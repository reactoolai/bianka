# Bianka Villeneuve Notaire — site Vite

## Démarrer
```
npm install
npm run dev
```
Production : `npm run build` → dossier `dist/` à déposer sur l’hébergement.

## Structure
- `index.html` — tout le contenu (accueil + pages des deux notaires)
- `src/main.js` — animations, diaporama, navigation, formulaire
- `src/style.css` — styles globaux et états de survol
- `public/images/` — photos et logo
